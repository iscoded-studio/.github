# Good ideas deserve good code.

isCoded is an independent software studio. We build software for clients and ship open-source tools for developers.

## What we build

- **Apps and experiences** for the web and desktop, including games.
- **Systems and integrations** that connect products, from APIs to servers.
- **Developer tools** including command-line utilities and MCP integrations.

## Open source

[**xeploy**](https://github.com/Hussain7Abbas/xeploy) is a command-line tool for GitHub releases. It guides teams through prereleases, production promotions, and branch synchronization.
